# Databricks Charts – Launcher

Startseite des PowerPoint-Add-ins „Databricks Charts“. Databricks Apps liefern ohne Anmeldung keine Seite aus und die
Microsoft-Anmeldung läuft nicht im Office-Aufgabenbereich; diese statische Seite öffnet deshalb die Anmeldung in einem
Office-Dialog und wechselt danach zur App. Sie enthält keine Daten und keine Zugangsdaten.

- `launcher.html` / `launcher.js` – Startseite (Sitzungsprüfung, Anmeldedialog, Wechsel zur App)
- `go.html` – Startseite des Anmeldedialogs
- `config.js` – Adresse der Databricks App
